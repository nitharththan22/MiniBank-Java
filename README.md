# Simple Banking Application

## Overview
This is a simple **Banking Program** written in **Java** that allows users to:
- **Check their balance**
- **Deposit funds**
- **Withdraw funds**
- **Exit the program**

The program runs on a loop until the user chooses to exit.

## Features
- Uses a `while` loop to continuously offer banking options.
- Supports **basic validation** for deposits and withdrawals.
- Implements **switch-case expressions** for better readability.
